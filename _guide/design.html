디자인 기초 (색 · 글꼴 · 모양)

css/common.css에 정해 둔 값을 한곳에 모은 기준 페이지. 새 요소를 만들 때 색·글꼴·크기는 여기 값에서 고르고, 값을 새로 만들지 않음. 견본은 공용 CSS 변수로 그리므로 :root 값을 고치면 이 페이지도 같이 바뀜.

    1. 색 — :root 의 --c-*

    CSS에서는 var(--c-ink) 처럼 이름으로 씀. 이미지 안의 색은 이 표에 없음.

    2. 버튼 색 (.card-btn 전용 값)

    변수가 아니라 .card-btn 규칙 안에 직접 적힌 값. 버튼 모양을 바꿀 때만 봄.

    4. 글자 크기 단계 (Cafe24 Ssurround, 화면 기준 px)

    공용 CSS에서 쓰는 큰 글자 크기. 말풍선은 글이 길면 자동으로 is-medium(44px) → is-large로 커짐.

    크기쓰는 곳견본
    80px모달 제목 .avatar-card-title모달 제목
    76px페이지 제목 .page-title · 목차 제목페이지 제목
    70px카드 버튼 .card-btn · 제목 알약 .ask-pill카드 버튼
    60px모달 본문 .avatar-card-text · 힌트모달 본문 글자
    50px작은 알약 .ask-pill.is-small작은 알약 글자
    48px말풍선 기본 .guide-bubble말풍선 기본 글자
    44px말풍선 긴 글 .is-long말풍선 긴 글자
    40px말풍선 작게 .is-small말풍선 작은 글자

    글자 간격은 대부분 -0.04em ~ -0.08em(좁게). 더 좁혀야 할 때 쓰는 클래스: 말풍선 .is-tight(-0.08em), 알약 .ask-pill.is-tight.
