퀴즈 풀기

제목이 "퀴즈 풀기"인 13개 페이지 가운데 유형이 겹치지 않게 대표 4곳(sa/01:14 · sa/04:14 · gwa/01:11 · gwa/07:11)만 나열한 페이지. 나머지 차시는 아래 표의 위치를 해당 페이지에서 직접 확인. 미리보기는 각 페이지의 소스(화면 영역)를 그대로 가져와 그린 것이라 요소 검사로 바로 확인할 수 있음 (주소 끝에 ?step=N).
구조는 모두 정적 마크업 — .step-flow 안에 문항마다 .step-panel, 보기는 .answer-pick(공용 기능 V), 보기 배치는 공용 .quiz-opts + .is-row(한 줄)/.is-grid(2×2)/.is-list(세로, 긴 보기는 .is-left), O/X는 .ox-pick, 그래프 보기는 .quiz-graphs, 빈칸 끌어 넣기는 .quiz-flow·.quiz-card + initMatchDrag. 퀴즈 13개 페이지 모두 페이지 전용 CSS 없이 공용 클래스만 씀(확인: 사회 8개·과학 5개 페이지의 <style>에 규칙 없음).
