폰 화면 틀

폰 모양 화면(Canva·검색 앱 등)을 그릴 때 쓰는 틀·상단·하단 모양을 모아둔 가이드. 틀은 공용 .phone-frame(left·top·width·height는 페이지 CSS에서), 아래 폰은 줄여서 보여주는 데모입니다. 카메라 홀 .has-cam · 상단 .phone-status · 하단 .phone-nav는 모두 공용이고, 안쪽 화면(앱바·본문·탭)만 페이지마다 다릅니다.

    앱 첫 화면 — 앱 아이콘만 가운데

    활동 시작 때 폰 가운데에 앱 아이콘 하나만 놓고 손가락으로 누르게 하는 화면. ChatGPT 화면 기준으로 아이콘 크기(110px · 모서리 28px)와 아래 앱 이름(20px · 굵게)을 모두 통일했고, 틀은 모두 .phone-frame으로 통일, 배경은 각 페이지 그대로. 이름 글자색은 어두운 배경에서는 흰색(+그림자), 밝은 배경에서는 검정. 모든 폰에 상단 정보(.phone-status)와 하단 버튼 3개(.phone-nav)를 붙임. 손가락은 공용 pointFingerAt처럼 아이콘 오른쪽 아래.

    기본 세트 — Canva가 아닌 화면

    틀 + 상단 + 하단 버튼을 붙인 기본 모양. 밝은 화면은 상단 .phone-status.is-dark(글자 검정), 어두운 화면은 화면 바닥 .phone-screen.is-dark(공용) 하나로 한 번에(배경 #111 · 글자 흰색 · 상단·하단 버튼 모두). 카메라 홀 .phone-frame.has-cam은 모두 기본.

    키보드 모음 — 페이지에서 쓰는 종류

    폰 안 글자 입력 장면에 쓰는 키보드를 한자리에 모았습니다(화면은 키보드만 보이게 비워 둠). 지금 2종류(천지인 A, 두벌식 B·C)입니다. 두벌식 B·C는 같은 공용 CSS .kbd-db 한 벌이고 색만 .is-dark로 바뀝니다(VLLO·Gemini Notebook 키보드도 이 둘로 통일). 키보드 색은 밝은 것(B)과 어두운 것(A·C)입니다.

    Gemini Notebook 앱 화면 — 공용 .gn-*

    Gemini Notebook 앱을 폰에 그릴 때 쓰는 공용 부품(과학 1차시 p10~15에서 시작, 사회 15차시 AI 실습에서 보강). 틀은 공용 .phone-frame.has-cam, 안쪽 화면은 .gn-screen. 아이콘 그림은 img/common/gn_*.png(gn_app_icon · gn_search · gn_start · gn_photo · gn_src_* · gn_tab_*), 나머지 아이콘은 SVG 입니다. 보였다 안 보였다 하는 부품은 .gn-off를 붙였다 뗍니다. 홈 화면은 .app-home.is-purple + gn_app_icon.png.
