리본 제목

화면 제목 판(리본)이 페이지마다 따로 그려져 있어서 모양을 모아 비교하는 가이드. 지금 CSS로 그린 리본은 3종이며, 같은 모양(A·B)은 폭·꼬리 위치만 다르고 색·테두리·접힘 무늬가 같습니다. A·B는 이제 공용 .ribbon 템플릿(맨 위 섹션)으로 만들어 sa/02:06·14에 적용했고, 아래 A·B 그림은 공용화 전 페이지 CSS를 옮긴 복사본(비교용)입니다. C는 아직 페이지 전용입니다.

    공용 템플릿 .ribbon — 변수로 크기·색·꼬리 조절

    공용 CSS(css/common.css)에 .ribbon 클래스를 만들었습니다. 위 A·B처럼 같은 모양에서 가로·높이·글자 크기·색·꼬리 길이를 CSS 변수로 바꿔 씁니다. 마크업 <div class="ribbon-wrap"><p class="ribbon" style="--rb-bg:#fff4d6">제목</p></div> — 꼬리가 판 뒤로 들어가려면 부모가 새 층을 만들어야 해서 .ribbon-wrap(isolation:isolate) 또는 기존 틀(z-index가 있는 카드)이 필요합니다. 위치(left/top)는 페이지 CSS에서.
