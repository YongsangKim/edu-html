UI 가이드

여러 차시에 반복되는 화면 요소를 카테고리별로 모아, 공용 css/common.css로 그린 모습을 보면서 맞추는 작업용 페이지.
진행 방식: 같은 역할의 요소를 모아 비교 → 기준 정하기 → 공용 CSS로 옮기고 페이지에 적용 → 적용된 모습만 남김.
